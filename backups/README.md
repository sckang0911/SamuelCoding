# Backups

Files downloaded from the **Download backup** button on the site, named
`samuel-coding-log-YYYY-MM-DD.json`.

Committing them here versions Samuel's whole history — every WPM score, every patch note,
every brick — so a lost or wiped device costs nothing.

Restore by loading a file with **Restore from backup** on the site. It replaces what is on
that device, so restore the newest one.
