# Games

Samuel's finished games live here, one HTML file each.

**Naming:** `NN-slug.html` — two-digit mission number, then a short slug.

```
games/01-atom-factory.html
games/02-brick-catcher.html
```

**How a game gets here:** he finishes it in Claude, downloads the artifact as HTML,
and it is uploaded to this folder. The matching brick on the main page then becomes
a play button, and the game appears in the arcade.

`index.html` in this folder is the shareable arcade page — not yet built.
See `../docs/redesign-spec.md` section 6.
